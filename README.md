TopDownRPG is a multiplayer-ready RPG prototype built in Unreal Engine 5 using the Gameplay Ability System (GAS). 
The project focuses on creating a scalable and maintainable game architecture while implementing core RPG mechanics 
such as character attributes, abilities, combat, progression, enemy AI, and UI systems.

The project demonstrates advanced Unreal Engine development practices, including custom Gameplay Abilities and Effects, 
Gameplay Tags, attribute-driven combat calculations, experience and level progression systems, Behavior Tree and EQS-based AI, 
spell casting, save/load functionality, and modular UI architecture. It also explores multiplayer replication, 
asynchronous asset loading, and a clean C++/Blueprint workflow designed for long-term project scalability.

Developed while following Stephen Ulibarri's Gameplay Ability System RPG course, this repository serves as both a playable 
top-down RPG prototype and a showcase of Unreal Engine 5 gameplay programming, GAS architecture, AI systems, 
and multiplayer-ready gameplay features.
